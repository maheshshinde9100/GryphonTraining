# Inheritance in python

class Person:
    def __init__(self,name,age,gender):
        self.name = name
        self.age = age
        self.gender = gender
        print("parent constructor is called...")
    def display(self):
        print(self.name,self.age,self.gender)

class Student(Person):
    def __init__(self,name,age,gender):
        print("Child constructor is called...")
    pass

object = Student('Steve',20,"Male")    #output : Child constructor is called...
# object.display()    

NOTE :  If CHILD class constructor is not available then calling the PARENT class constructor

#Exception Handling
1.Syntax error
2.Semantic (Logical Error)
3.Runtime (Exception)

@Types of Error
1. ValueError -> Occurs when the type is correct byt the value is invalid

ex., 
try:
   age = int("twenty")
except ValueError:
    print("Invalid value for Integer Conversion")

output -> Invalid value for Integer Conversion

2. TypeError -> occurs when operation is performed on incompatible Types
ex.,
try:
    result = "10"+5
except TypeError:
    print("TypeError occurred")

output -> TypeError occurred

3. IndexError -> Occurs when accessing as invalid index of sequences (for lists, tuples)
4. KeyError -> When key is not present in Dictionary (for dictionaries)
5. FileNoFoundError -> if file now exist
